## Usage

Chart wraps Recharts, an optional peer dependency. Install it alongside the library:

<InstallCommand packages="recharts" />

```tsx
import {
  type ChartConfig,
  ChartContainer,
  ChartLegend,
  ChartLegendContent,
  ChartTooltip,
  ChartTooltipContent,
} from "@neomorphic-react/ui/chart";
import { Bar, BarChart, XAxis } from "recharts";
```

```tsx
const config = {
  solar: { label: "Solar", color: "var(--chart-5)" },
  grid: { label: "Grid", color: "var(--chart-1)" },
} satisfies ChartConfig;

<ChartContainer className="h-64 w-full" config={config}>
  <BarChart data={data}>
    <XAxis dataKey="month" />
    <ChartTooltip content={<ChartTooltipContent />} />
    <ChartLegend content={<ChartLegendContent />} />
    <Bar dataKey="solar" fill="var(--fill-solar)" radius={8} />
    <Bar dataKey="grid" fill="var(--fill-grid)" radius={8} />
  </BarChart>
</ChartContainer>
```

You write the chart with Recharts' own components, and `ChartContainer` sizes it, styles its axes, grid and cursor to match the surface, and turns `config` into colour variables. The chart itself is flat, so put it on a [Card](/docs/components/card). Each key in `config` gives three variables:

- `--color-<key>`: the plain colour, for lines, dots and slices.
- `--fill-<key>`: a gradient that darkens towards the base, for bars.
- `--area-<key>`: the colour fading away, for areas.

The `--chart-1` to `--chart-5` theme tokens are a good place to start. For one value against a maximum, use a [Bar Meter](/docs/components/bar-meter) or [Progress](/docs/components/progress); for exact figures people need to read and compare, use a [Table](/docs/components/table).

## Examples

### Area

`fill="var(--area-<key>)"` fills each area with its colour fading towards the axis, and `stroke="var(--color-<key>)"` draws the edge. `stackId` stacks the series. `indicator="line"` on the tooltip marks each row with a bar of colour instead of a dot.

<ComponentPreview name="chart-area" />

### Line

Lines use `--color-<key>` for the stroke and the dots. A dashed stroke tells the second series apart without relying on colour. The legend and tooltip take their labels from `config`.

<ComponentPreview name="chart-line" />

### Pie

When each slice is its own series, key `config` by the slice's name and set each slice's `fill` to its `--color-<key>` in the data. `nameKey` tells the tooltip and the legend which field holds that key. `hideLabel` drops the tooltip's heading, which a single slice doesn't need.

<ComponentPreview name="chart-pie" />

### Tooltip and legend

An `icon` in `config` replaces the colour dot in the tooltip and the swatch in the legend; `hideIcon` keeps the legend's swatches so it still works as a colour key. `labelFormatter` rewrites the tooltip's heading. A stack of bars takes a `radius` on the top one only.

<ComponentPreview name="chart-tooltip" />

### In context

A weekly activity card. A [Toggle Group](/docs/components/toggle-group) in the header picks the measure, and the bar's `dataKey` and `fill` follow it, while the description gives the total in text.

## Accessibility

- Recharts makes each chart focusable, with `role="application"`. In a chart with a category axis, the left and right arrow keys move the tooltip from one point to the next, and Enter hides or shows it.
- A chart's shapes say little to a screen reader. Put the figure that matters in text beside it, as the card descriptions here do, or pass `title` and `desc` to the Recharts chart.
- Name every series in `config`, so the tooltip and legend say what each colour is. Where series sit close together, tell them apart by more than colour, for example with a dashed line.
- The gradient definitions the container adds are hidden from assistive technology.

## API reference

### ChartContainer

Takes every prop of the native `<div>`. Size it with `className`: it's `aspect-video` by default.

| Prop | Type | Default |
| --- | --- | --- |
| `config` | `ChartConfig` | – |
| `children` | A Recharts chart, such as `BarChart` or `PieChart` | – |
| `responsiveProps` | Props of Recharts' `ResponsiveContainer`, apart from `children` | – |
| `id` | `string` | Generated |

`config` and `children` are required. `id` names the gradients the variables point to.

### ChartConfig

```ts
type ChartConfig = Record<
  string,
  {
    label?: ReactNode;
    color?: string;
    icon?: ComponentType;
  }
>;
```

Keyed by each series' `dataKey`, or by the value of the field `nameKey` points to. `color` takes any CSS colour, and only keys with a `color` get variables. Characters other than letters, digits, `_` and `-` become `_` in the variable names, so a `"mobile users"` key gives `--color-mobile_users`.

### ChartTooltip and ChartTooltipContent

`ChartTooltip` is Recharts' [Tooltip](https://recharts.github.io/en-US/api/Tooltip/) and takes all its props; pass `content={<ChartTooltipContent />}`. `cursor={false}` turns off the highlight behind the hovered point.

`ChartTooltipContent` is a small raised card listing the hovered series. Recharts passes it `active`, `payload` and `label`.

| Prop | Type | Default |
| --- | --- | --- |
| `indicator` | `"dot" \| "line" \| "dashed"` | `"dot"` |
| `hideLabel` | `boolean` | `false` |
| `hideIndicator` | `boolean` | `false` |
| `nameKey` | `string` | – |
| `labelKey` | `string` | – |
| `labelFormatter` | `(label: ReactNode, payload) => ReactNode` | – |
| `labelClassName` | `string` | – |
| `formatter` | `(value, name, item, index, payload) => ReactNode` | – |
| `color` | `string` | – |
| `className` | `string` | – |

`nameKey` and `labelKey` name the payload field that holds the `config` key for each row and for the heading. `formatter` replaces each row's marker, name and value with what it returns. `color` sets every row's marker colour. Numbers are formatted for the reader's locale.

### ChartLegend and ChartLegendContent

`ChartLegend` is Recharts' [Legend](https://recharts.github.io/en-US/api/Legend/) and takes all its props; pass `content={<ChartLegendContent />}`. `ChartLegendContent` is a centred row of swatches and labels from `config`.

| Prop | Type | Default |
| --- | --- | --- |
| `nameKey` | `string` | – |
| `hideIcon` | `boolean` | `false` |
| `verticalAlign` | `"top" \| "middle" \| "bottom"` | `"bottom"` |
| `className` | `string` | – |

Recharts passes `verticalAlign` on from `ChartLegend`. At `"top"`, the space sits under the legend instead of above it.

### useChart

Returns `{ config }` from the surrounding `ChartContainer`, for your own tooltip or legend content. It throws outside one.

### Data attributes

| Attribute | Values |
| --- | --- |
| `data-slot` | `"chart"`, `"chart-tooltip"`, `"chart-tooltip-item"`, `"chart-tooltip-indicator"`, `"chart-legend"` or `"chart-legend-item"` |
| `data-chart` | On the container, the id its gradients are named from |

### CSS variables

Set on the container for each key in `config` that has a `color`.

| Variable | Sets |
| --- | --- |
| `--color-<key>` | The series' colour |
| `--fill-<key>` | A gradient from a darker shade at the base to the colour at the top, for bars |
| `--area-<key>` | The colour fading from half opacity at the top to almost nothing at the base, for areas |
