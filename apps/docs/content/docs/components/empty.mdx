## Usage

```tsx
import {
  Empty,
  EmptyContent,
  EmptyDescription,
  EmptyHeader,
  EmptyMedia,
  EmptyTitle,
} from "@neomorphic-react/ui/empty";
```

```tsx
<Empty>
  <EmptyHeader>
    <EmptyMedia variant="icon">
      <Plane />
    </EmptyMedia>
    <EmptyTitle>No trips yet</EmptyTitle>
    <EmptyDescription>Trips you book show up here.</EmptyDescription>
  </EmptyHeader>
  <EmptyContent>
    <Button variant="primary">Book a trip</Button>
  </EmptyContent>
</Empty>
```

Show an empty state where a list, table or search would show results but has none: say why it's empty and offer the next step. While the content is still loading, use a [Skeleton](/docs/components/skeleton) or a [Spinner](/docs/components/spinner) instead, so the empty state never flashes up before the data arrives.

## Examples

### In a well

`flat` (the default) sits level with the surface, for a whole page or a large panel. `inset` sets the empty state in a shallow well, so it reads as an empty region inside a page or card.

<ComponentPreview name="empty-inset" />

### Avatars and illustrations

`EmptyMedia` with `variant="icon"` puts an icon on a raised tile. With the `default` variant it leaves its child as it is, so an [Avatar](/docs/components/avatar) group or an illustration can stand in for the icon.

<ComponentPreview name="empty-avatars" />

### Several actions

`EmptyContent` stacks its children in a column, centred. Put buttons in a row inside it when there's more than one next step. Links in `EmptyDescription` are underlined.

<ComponentPreview name="empty-actions" />

### In context

A notifications card. Clearing the list swaps it for an inset empty state that says why it's empty, with a button to bring the notifications back. Focus moves to that button, because the one that was pressed is now disabled.

## Accessibility

- The parts render plain `<div>`s and a `<p>`, with no roles. `EmptyTitle` isn't a heading; when the empty state stands in for a section of the page, put a heading of the right level inside it, such as `<EmptyTitle><h2>No trips yet</h2></EmptyTitle>`.
- The icon is decorative. lucide-react icons are hidden from screen readers by default; give any other SVG `aria-hidden`.
- When the empty state replaces content after an action, such as clearing a list, move focus to its button or announce the change, so keyboard and screen reader users know what happened.
- Buttons and links inside keep their own roles and focus rings.

## API reference

### Empty

The centred column holding the header and content. Renders a `<div>` and takes every prop of it.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"flat" \| "inset"` | `"flat"` |

### EmptyHeader

Holds the media, title and description, up to 384px wide. Renders a `<div>` and takes every prop of it.

### EmptyMedia

The icon, avatar or illustration above the title. Renders a `<div>` and takes every prop of it.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "icon"` | `"default"` |

### EmptyTitle, EmptyDescription and EmptyContent

`EmptyTitle` is the title and `EmptyDescription` the explanation under it, in `--muted-foreground`. `EmptyContent` holds the next step, up to 384px wide. `EmptyDescription` renders a `<p>`, the others a `<div>`, and each takes every prop of its element.

### emptyVariants and emptyMediaVariants

```ts
emptyVariants(options?: { variant?: "flat" | "inset" }): string;
emptyMediaVariants(options?: { variant?: "default" | "icon" }): string;
```

Return the class names of the root and of the media.

### Data attributes

| Attribute | Values |
| --- | --- |
| `data-slot` | `"empty"`, `"empty-header"`, `"empty-media"`, `"empty-title"`, `"empty-description"` or `"empty-content"` |
| `data-variant` | On the root and on `EmptyMedia`, the `variant` |
