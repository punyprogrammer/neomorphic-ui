## Usage

```tsx
import { Badge, BadgeAnchor } from "@neomorphic-react/ui/badge";
```

```tsx
<Badge count={12} variant="primary" />

<BadgeAnchor>
  <Button aria-label="Notifications, 3 unread" icon={<Bell />} size="lg" />
  <Badge count={3} placement="top-end" />
</BadgeAnchor>
```

Badges are for counts, dots and one-word labels such as "New". For an icon and a label, such as "Paid" or "Due soon", use [Chip](/docs/components/chip).

## Examples

### Variants

`default` is raised from the surface and `inset` is pressed into it. `primary`, `destructive`, `success` and `warning` are token fills, each paired with its `-foreground` colour so the text keeps its contrast.

<ComponentPreview name="badge-variants" />

### Sizes

`sm`, `md` (the default) and `lg` set the height, padding and text size. A badge is at least as wide as it is tall, so a single digit stays a circle and longer counts grow into a pill.

<ComponentPreview name="badge-sizes" />

### Counts

`count` shows a number. Above `max` (99 by default) it reads `max+`. A count of zero hides the badge unless `showZero` is set. When you pass `children`, they're shown instead of `count`.

<ComponentPreview name="badge-counts" />

### Dots

`dot` draws a small circle with no content, for "something new" without a number. A dot on its own carries no text, so put the meaning next to it in words.

<ComponentPreview name="badge-dots" />

### Placement

Inside a `BadgeAnchor`, `placement` pins the badge to a corner and centres it on that corner, whatever its size. `start` and `end` follow the writing direction, so they flip in right-to-left layouts. On a round anchor the corner of the bounding box is empty, so `overlap="circular"` moves the badge in onto the anchor's edge.

<ComponentPreview name="badge-placements" />

### In a button

Without a `placement`, a badge sits inline, so it can follow a button's label.

<ComponentPreview name="badge-in-button" />

### Changing counts

A placed badge is hidden from assistive technology, so keep the count in the anchored control's accessible name and update both together. At zero the badge disappears.

<ComponentPreview name="badge-live" />

### In context

A shop header with saved-item and bag counts that update as the shopper adds items.

## Accessibility

- A badge with a `placement` is `aria-hidden` by default. Put the count in the anchored control's accessible name instead, for example `aria-label="Notifications, 3 unread"`, so it's announced with the control.
- A placed badge ignores pointer events, so clicks and taps on its corner reach the control underneath.
- An inline badge is ordinary text. Inside a button it becomes part of the button's accessible name.
- When `count` is zero and `showZero` isn't set, the badge renders nothing.
- `--success` and `--warning` fall below the 3:1 minimum contrast as text on the surface, so they're only offered as fills with their `-foreground` text.

## API reference

### Badge

Renders a `<span>` and takes every prop of the native `<span>`. Use `render` to render a different element.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "inset" \| "primary" \| "destructive" \| "success" \| "warning"` | `"default"` |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` |
| `count` | `number` | – |
| `max` | `number` | `99` |
| `showZero` | `boolean` | `false` |
| `dot` | `boolean` | `false` |
| `placement` | `"top-end" \| "top-start" \| "bottom-end" \| "bottom-start"` | – |
| `overlap` | `"rectangular" \| "circular"` | `"rectangular"` |

### BadgeAnchor

The positioning context for badges with a `placement`: an inline `relative` wrapper around the control. Renders a `<span>` and takes every prop of the native `<span>`, plus `render`.

### badgeVariants

```ts
badgeVariants(options?: {
  variant?: "default" | "inset" | "primary" | "destructive" | "success" | "warning";
  size?: "sm" | "md" | "lg";
  dot?: boolean;
  placement?: "top-end" | "top-start" | "bottom-end" | "bottom-start";
  overlap?: "rectangular" | "circular";
}): string;
```

Returns the badge's class names, for styling another element as a badge.

### Data attributes

| Attribute | Values |
| --- | --- |
| `data-slot` | `"badge"`, or `"badge-anchor"` on the anchor |
| `data-variant` | The `variant` |
| `data-size` | The `size` |
| `data-placement` | The `placement`, when set |
| `data-dot` | Present when `dot` is set |
